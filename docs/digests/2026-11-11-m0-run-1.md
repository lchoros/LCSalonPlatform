## Tier 2 merges for the owner to veto or revert
- **Outbox table outside tenant RLS** (`agent/m0-10-events-outbox`, ADR 0007): the dispatcher reads across tenants, so
  `outbox_messages` is platform-level with a nullable `tenant_id`. Mitigations: allow-list in `TenantEntityTests`,
  `OutboxIsolationTests` forbids any dependency on `OutboxMessage` outside `Salon.Services.Events`, consumers run in
  the message's tenant scope. Alternative in the ADR: tenant-owned table + per-tenant dispatch.
- Tenancy (#2, #4), settings table (#8): forced RLS on every tenant table; migrations' `Down` drops tables.
- Governance (#15): approval workflows removed, CI changed.

## Reviews
Until the process change, an independent Reviewer agent reviewed each PR; afterwards the Orchestrator reviewed the
diffs itself. All findings were fixed before the PR was opened; each PR carries one review comment. Notable fixes:
Hangfire shared lock → one per task; cache eviction race; duplicate handler detection; localization silent overwrites
and `_ViewImports` scope; outbox per-row save so a poison row cannot block the batch; xmin concurrency token; eager
registry validation; the test host's stale tenant cache after a Respawn reset.

## Decisions made (owner may veto)
- ADR 0002 — tenant isolation: scoped context + named EF filter + forced Postgres RLS keyed on `app.tenant_id`.
- ADR 0003 — in-house dispatcher instead of MediatR (licence, two interfaces needed).
- ADR 0004 — typed settings one row per property, per tenant only, cache prefix invalidation; distributed cache at M3.
- ADR 0005 — schedule tasks as Hangfire recurring jobs with `DisableConcurrentExecution`; jobs iterate tenants through fresh scopes.
- ADR 0006 — localization from embedded JSON per assembly, validated at startup, no cross-source overrides; request culture query → cookie → tenant → Accept-Language → en-GB.
- ADR 0007 — transactional outbox: publisher saves on the handler's DbContext; at-least-once delivery; dispatcher per tenant scope with retry and dead-letter; outbox table exempt from RLS (Tier 2).
- CreateService admin form ships behind `Features:CatalogAdmin` (default off) because authentication does not exist yet.
- CodeQL runs without SARIF upload (needs Advanced Security on a private repo) and fails the job on any finding.
- Local machine: PostgreSQL 17 on port 5433 next to the existing 12 on 5432; Mailpit, Tailwind CLI and `gh` via winget.
