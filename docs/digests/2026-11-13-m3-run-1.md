pages, and every booking email ends with the address. Texts are unchanged. One additive migration.

## Decisions made (ADR 0026, "owner may veto")
- **The till's rules add the money up.** A report sums the same ledger lines with `TillRules`; a test asserts a
  one-day report equals that day's till. No second definition of takings.
- **Money counts on the day it was recorded, a visit on the day it starts**, both in the salon's zone.
- **A rate without a base is unknown, not zero.** An empty week does not read as a week without no-shows.
- **Utilisation** is booked time over the rota less time off. It uses the rota as it is today, so an old period is
  an estimate if the rota changed.
- **Negative money reads −£10.00**, not £-10.00, everywhere, the till included.

## Decisions made in #69 (ADR 0027, "owner may veto")
- **Locations start as one.** The entity exists; several sites per salon wait for a salon that has two.
- **Emails get a footer, texts do not.** An address would push most texts into a second SMS segment.
- **The maps link is a plain link** to a Google Maps search for the address. No script, no key.
- **Times stay in the tenant's zone.** One location, one zone per market.
