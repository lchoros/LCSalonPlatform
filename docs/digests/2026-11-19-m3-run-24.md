## Decisions made
- **Sign-up now, flag off by default**: the pilot needs a door, a deployed instance does not need an open one.
  `Features:SignUp` is on in Development and the test hosts only.
- **No cross-host auto sign-in**: the done page hands over the salon's own sign-in address; the cookie stays
  host-scoped (ADR 0009). One extra password entry beats a token hand-off surface.
- **`TenantSlugRules` in Core**: the web address is a domain label with the platform's names kept back; the
  database's unique index settles a race and the loser reads the same "taken" message.
- **No email verification yet**: phase 1 has no real email; named in the ADR as wanted before the flag is ever on
  in public, with rate limiting.
- **The pipeline's own guard found the design hole**: a command with no tenant in scope is refused unless it is
  `IPlatformRequest` — sign-up is exactly that, and the exception message said so.
