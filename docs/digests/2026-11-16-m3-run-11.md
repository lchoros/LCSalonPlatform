## Decisions made
- **Work past the limit is a branch, not a sixth PR.** The limit is on open PRs. The owner asked for more work while
  five were open, so the work waits as branches and the count of open PRs stays at five.
- **The stock file uses the import's headings** (ADR 0047), so one salon's file is another's product list. A test
  proves the round trip in English and in Polish.
- **No file of clients.** It would hold phone numbers, email addresses and consent: the owner's call.
- **The chart is plain SVG written by the server** (ADR 0048). A chart library would be a new runtime dependency,
  which is Tier 2. The geometry is a pure, tested class in Core.
- **Charts for 2 to 62 days only.** One day is one number; more than two months of bars do not fit a phone.
- **The CSV download plumbing sits once in `SalonControllerBase.CsvDownload`**; the money file uses it too. Its
  tests did not change.
