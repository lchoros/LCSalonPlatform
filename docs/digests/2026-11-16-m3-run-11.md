## Decisions made
- **More than five open PRs, on the owner's word.** CLAUDE.md still says five; the owner's message of 2026-11-16
  lifts it for now. Changing the file is his.
- **The stock file uses the import's headings** (ADR 0047), so one salon's file is another's product list. A test
  proves the round trip in English and in Polish.
- **No file of clients.** It would hold phone numbers, email addresses and consent: the owner's call.
- **The chart is plain SVG written by the server** (ADR 0048). A chart library would be a new runtime dependency,
  which is Tier 2. The geometry is a pure, tested class in Core.
- **Charts for 2 to 62 days only.** One day is one number; more than two months of bars do not fit a phone.
- **Only the owner and managers see what a product costs** (ADR 0049). The controllers take the cost off the page
  for anybody else, so it is not in the markup either.
- **The worth of the shelves counts every product with units, in use or not**, and names how many have no cost, so
  the figure at cost is not taken for the whole.
- **No profit in the reports yet.** An honest profit needs the cost of the day on the bill line, which is a column
  on a payments table: Tier 2, the owner's call.
- **The stock file and the import example gained a cost column.** Their tests were changed to the new format; no
  test was weakened.

## What was learned
- A number written into an SVG attribute through Razor takes the reader's decimal sign. Format it invariant and
  test it with the Polish salon.
- Polish money uses a no-break space as its thousands sign too; compare the digits, not the string.
- The worktree has no Python; perl and the edit tools do the same work.
