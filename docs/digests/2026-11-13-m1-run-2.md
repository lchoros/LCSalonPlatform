## What was learned
- **The intermittent 30-second E2E timeouts had one cause**: `page.WaitForURLAsync` can miss the load event on a cold
  process (the first run after a build, so every CI run). Reproduced on demand with `dotnet build --no-incremental`;
  fixed by `ReachAsync` and guarded by an architecture test. Reruns had only been hiding it.
- CI pages are unstyled (no Tailwind step), so a test must click the link or button itself, not a row around it.
- Assertions such as "the page does not contain PPD" (three letters, case-insensitive) fail by chance against random
  tokens; they now use whole phrases.
- Appending every slice's strings to two shared JSON files made every pair of branches conflict; per-module files end
  that.
- A conflicting PR gets no CI run at all, and CodeQL runs only on `main`, so a finding appears one merge late.
