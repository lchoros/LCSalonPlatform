## Decisions made
- **Stack, don't wait**: with several open PRs touching the same doc files, merge the lower branch into the next
  (bottom-up, merge commits) instead of waiting for the owner between each merge.
- **`main`'s security-scan failed after #118**: CodeQL `cs/exposure-of-sensitive-information` — the outcome of
  `EmailAsync` is tainted by the client's email address, and `$"Payments.Receipt.NotSent.{outcome}"` carried that
  taint into the missing-resource warning log. #120 picks literal keys per case; same keys, same texts, no scanner
  config touched. CodeQL runs on `main` only, so the proof lands with the merge.
- **The set-up note is a view component** (the `VisitsWithoutOutcome` pattern): the day list and the calendar both
  show it and neither slice may reference the other or the getting-started slice. The checklist rules moved to
  `ISetupProgressService` in `Salon.Services`; the page and the note can never disagree.
- **Owner only**: nobody else could open the page the note leads to.
