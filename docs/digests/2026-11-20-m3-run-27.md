## Decisions and findings
- **Why CI was red on the first pushes**: CI serves pages without the stylesheet; the unsized menu icon grew to the
  width of the screen and pushed every form's button below the fold, so three E2E walks failed on CI only. Icons
  now state their size in the markup (a page whose CSS failed to load is usable again) and an architecture test
  holds it. To reproduce a CI-only E2E failure: take `wwwroot/css/app.css` away and run the suite.
- **The empty `/book` after a restart** (ADR 0090): the tenant reached Postgres as a session setting, apart from
  the query. Behind a pooler in transaction mode the two can land on different server connections — the page sees
  nothing, and with another salon's id left in a shared session the database wall could have pointed at the wrong
  salon. Reproduced with a simulator, not against the host's own pooler (its mode is unknown); the fix is right
  either way and also repairs public sign-up for a non-superuser login. The hourly heartbeat now says whether a
  pooler shares sessions.
- ADR numbers 0082–0084 and 0086–0090 are taken; 0085 is a gap left by parallel lanes.
