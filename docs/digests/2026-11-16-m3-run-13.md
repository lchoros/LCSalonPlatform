## Decisions made
- **A return of a counter sale has no client either** (ADR 0054). The database guard is widened by exactly that
  kind of line and nothing else.
- **The units are claimed in one statement**, so two tills cannot give the money back for the same unit.
- **The desk finds a counter sale by its day**, because it has no client and no visit to find it by.
- **The public waitlist is off until the owner switches it on, and the number is proven first** (ADR 0055). The
  text message check now says what a row is for, so a code sent for the waitlist cannot make a booking and the
  other way round.
- **Joining the list is not consent to marketing.** The form has no tick and none is recorded.
- **A card the salon already has is not rewritten from a public form.**
- **A real bug was found and fixed on the way** (ADR 0040 amendment, #100). Two requests for the same return on a
  visit's bill at the same moment could both record the money given back. A test that races six saw four recorded.
  The units are now claimed in one statement there too.
- **A freed time goes to one person, by one text, and nothing is held** (ADR 0056). The owner said to take the
  recommended options without asking, so this one, named as the natural next step in #99's review, was built. It
  is off until switched on, silent at night, and at most one text a day to the same person.
- **A second bug was found by a test that fails only now and then** (#102). The import change of #95, already on
  `main`, took a leading apostrophe off notes as well as phone numbers. A property test with random notes caught it
  in this run. The fix is its own PR on `main` so it does not wait for the stack.
- **A gift voucher used at the checkout moves no money** (ADR 0057). The takings have it on the day it was sold.
  It counts toward the visit like a deposit, so the one-payment checkout of ADR 0024 did not have to change.
- **Vouchers pay toward the visit only**, not products and not counter sales. That needs the product sale line
  split between a voucher and a method, and is left for its own change.
- **A slice's name must not begin with another slice's name.** The isolation test goes by the start of the
  namespace, so "CounterSaleReturns" read as part of "CounterSale". The slice is called `ReturnCounterSale`; the
  test was not touched.
