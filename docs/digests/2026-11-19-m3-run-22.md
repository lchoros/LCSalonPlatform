## Decisions made
- **Next was the variants line of ADR 0066**: the pilot salon's price list has treatments by hair length, and a
  file could not create a variant that groups on the booking page.
- **A column, not a convention**: splitting "Keratin · Long hair" on the separator would be silently wrong for a
  salon whose names use "·" themselves; an explicit Variant column is unambiguous, optional, and round-trips.
- **Two existing round-trip tests changed with the behaviour**: the exported file now has the Variant column, so
  their expected rows gained a cell.
- **The form keeps names and grouping**: the file never regroups an existing service (the ADR 0066 line stands).
