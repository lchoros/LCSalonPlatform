# Digest — the platform went live (2026-11-19, run 26)

The owner decided the evening's course in person: deploy now, real email now, demo salon on the server.

## Done
- **First deployment.** Merged `main` (through #125) runs at https://booking24.runasp.net on MonsterASP via
  WebDeploy; all migrations applied to the hosted PostgreSQL 18; HTTPS live once the owner enabled the certificate.
- **Real email** (ADR 0078): the SMTP sender learned STARTTLS and a login; the pilot relays through the owner's
  Gmail app password, configured only on the server. A test email was delivered on the owner's request.
- **The fake-SMS mirror became configurable** (`Sms:MirrorAddress`) and points at the owner's inbox on the server:
  every would-be text is readable there, nothing bounces.
- **The demo salon seeded itself on the server** (66 services, 3 staff, 12 clients, 6 engine-booked appointments,
  2 logins). The RLS wall of ADR 0002 held against the database's own login — a lovely accidental proof.

## Decisions
- The owner considered switching to SQL Server for the host's sake; after the trade-offs (official NodaTime mapping,
  UUIDv7 index order, Express limits, licence cost) they chose a host with PostgreSQL instead.
- Stack stays exactly as it is; phase-1 "no deploy, no real email" ended by the owner's word, not by drift.
