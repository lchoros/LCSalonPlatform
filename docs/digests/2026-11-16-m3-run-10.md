## Decisions made
- **A view says what to show, not how** (ADR 0043). The owner's question about the checkout view became a rule with
  a test behind it.
- **The three badge palettes for a visit's status were kept**, named and put in one file. Making them one is the
  owner's to ask for.
- **Three zeros switch the next-visit offer off** (ADR 0039 amendment), and the settings page shows what the desk
  will see with the same rule the checkout uses.
- **Returns in the reports are a sum of money, not units per product** (ADR 0044): the ledger does not say which
  product of a sale came back, and saying it needs an altering change to the money table.
- **An import never changes a product the salon already has** (ADR 0045). The name decides. Updating prices from a
  file is a different feature with more to go wrong, and is the owner's to ask for.
- **No feature flag on the product import.** The preview is the guard and nothing that exists is touched.
- **A period is compared with the same days one period earlier, only as far as today** (ADR 0046). A month in
  progress is not set against a whole month. The page gives the change in words and no verdict.
